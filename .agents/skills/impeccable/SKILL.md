# Impeccable Design Skill

Created by Paul Bakaus (creator of jQuery UI), **Impeccable** is a design intelligence discipline built to eliminate "AI slop" from code generated by AI coding assistants.

## The Core Philosophy: Eliminating "AI Slop"

AI coding models have ingrained visual clichés:
- Defaulting to plain Inter without intentional hierarchy.
- Cliche purple-to-blue gradients on dark backgrounds.
- Endless nested "card inside card inside card" containers with heavy borders.
- Flat visual hierarchy where headers, labels, and values blur together.
- Low-contrast, washed-out text on gray surfaces.
- Generic, robotic spacing that lacks rhythm.

**Impeccable replaces these habits with deliberate, human-grade craft.**

---

## 1. The 5 Impeccable Tenets

### I. Purposeful White Space & Rhythmic Density
- Use an **8px base grid** (4px for micro-spacing, 8px, 12px, 16px, 24px, 32px, 48px).
- Group related items closely (e.g., label + value = 4px gap).
- Separate distinct conceptual sections generously (24px to 32px).
- For dashboards, maintain **high information density** without claustrophobia: eliminate bloated padding around metrics.

### II. Contrast & Visual Hierarchy
- The most important number on any screen must be immediately readable from 10 feet away.
- Secondary metadata must be cleanly muted (`text-slate-400` or `text-slate-500`), but never below WCAG AA contrast (minimum 4.5:1 for normal text, 3:1 for large text).
- Use uppercase micro-labels (`text-[10px] font-mono tracking-wider uppercase text-slate-500`) to anchor dense metric cards.

### III. Tactile Surfaces & Optical Depth
- Avoid muddy gray-on-gray flat cards.
- Build depth with a **3-layer elevation system**:
  1. **Background**: Deep space canvas (`#080c14` or `#0b0f19`).
  2. **Panels/Surfaces**: Rich slate/navy (`#0f172a` or `#111827`).
  3. **Interactive Cards**: Elevated slate (`#1e293b`) with subtle rim highlights (`border border-white/5` or `border-slate-800`).
- Apply subtle glassmorphism (`backdrop-blur-md bg-slate-900/80`) to floating controls and sticky headers.

### IV. Tabular Precision for Data & Telemetry
- All numbers, timers, timestamps, and counters must use **tabular figures** (`font-mono` or `font-feature-settings: 'tnum'`) so values don't jump horizontally on update.
- Align numbers to the right in data tables; align text to the left.

### V. Intentional Motion & Micro-Interactions
- Keep transition durations between **150ms and 200ms** using `ease-out` for snappy, responsive feel.
- Never use distracting, bouncy animations for professional enterprise tools.
- Active states must feel tactile: subtle scale (`active:scale-[0.98]`) or brightness shift.

## 2. Invocable Sub-Skills
- `impeccable-critique`: Rigorous design review and heuristic evaluation.
- `impeccable-polish`: Pixel-level refinement pass on styling, shadows, and borders.
- `impeccable-typeset`: Typography scale, font pairing, and tabular figures.
- `impeccable-colorize`: Palette selection, contrast ratios, and semantic status colors.
- `impeccable-layout`: Grid density, bento layouts, and responsive flow.
